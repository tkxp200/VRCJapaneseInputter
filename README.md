# VRCJI(VRCJapaneseInputter)

## 概要

VRCJI(VRCJapaneseInputter)はVRChatで日本語入力をサポートするアプリケーションです。

動作にはWindows、SteamVRが必須となります。

## 使い方

使い方に関しては[ドキュメント(後で作る)]をご覧ください。
